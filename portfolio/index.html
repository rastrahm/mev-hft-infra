// 01 — CONTEXTO

Por qué este proyecto

Tras flash loans y AMM, construí la capa de searcher MEV: bundles estilo Flashbots, AtomicArbitrageSolver, BackrunExecutor y SandwichExecutor (lab). El foco es atomicidad (NegativeEV → revert sin tip residual), auth del searcher, gas Yul y SWC con tests que demuestran que el misuse falla.

Qué entrega el módulo

// PILAR_01

Solvers atómicos

Arb 2-router, backrun post-victim y sandwich lab con midHook: snapshot → MevSwapLib → tip → takeProfit.

  • UnauthorizedSearcher en los tres ejecutores
  • NegativeEV → revert atómico (sin bribe residual)
  • CEI + ReentrancyGuard + Ownable2Step

// 06 — CAMPAÑAS DEFENSIVAS

Defensivo, no ofensivo

Unauthorized, RevertOnUnprofitable, fuzz y tip reject: el “éxito” del misuse es que revierte y el tip no queda en coinbase. Sandwich solo lab. Sin PoCs de exploit.

A

Unauthorized

Caller ≠ searcher en arb/backrun/sandwich → UnauthorizedSearcher.

B

NegativeEV

Pools planos / price move → revert; tip no residual.

C

Tip reject

Coinbase RejectETH → TipTransferFailed; tx atómica.

D

Slippage

amountOutMin absurdo → MockAMM.SlippageExceeded sin tip.

E

Fuzz

Volumen, tip bps y flat pools ≥ 1000 runs.
